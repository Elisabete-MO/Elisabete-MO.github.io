<h3>🧑‍💻 Descrição do Projeto</h3>

Este repositório contém o código-fonte do meu portfólio web pessoal, desenvolvido com HTML, CSS e JavaScript. O objetivo do projeto é apresentar meus trabalhos de forma visual, interativa e organizada, servindo tanto como portfólio profissional quanto como exercício prático de front-end

O portfólio apresenta uma seleção de projetos e informações profissionais de maneira visual, interativa e organizada, priorizando clareza, identidade visual e boa experiência de navegação. A proposta é oferecer uma apresentação menos técnica do que a encontrada diretamente nos repositórios, sem deixar de evidenciar boas práticas de desenvolvimento.

O projeto é evolutivo e pode receber novas funcionalidades e melhorias visuais conforme o aprendizado avança.

---


## 🎯 Objetivos do Projeto

-   Aplicar conceitos fundamentais de **HTML5, CSS3 e JavaScript**
-   Desenvolver uma **página única (single page)** com navegação fluida
-   Trabalhar identidade visual e organização de layout
-   Demonstrar capacidade de estruturar e documentar um projeto front-end
-   Consolidar boas práticas de separação entre estrutura, estilo e comportamento

---

<h3>💻 Recursos</h3>

- Página única com navegação por scroll
- Identidade visual temática (cyberpunk / futurista)
- Interações e animações com JavaScript
- Exibição organizada de projetos
- Layout responsivo  

---

## 🛠️ Tecnologias Utilizadas

-   **HTML5** — estrutura semântica da página
-   **CSS3** — layout, responsividade e animações
-   **JavaScript (ES6+)** — interatividade e manipulação do DOM

O projeto foi desenvolvido **sem o uso de frameworks**, com foco no domínio das tecnologias base do front-end.
